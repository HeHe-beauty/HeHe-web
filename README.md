# HEHE Web

레이저 제모 병원 찾기 앱 **HEHE** 다운로드 유도용 지도 웹 랜딩 페이지

## 기술 스택

- Vue 3 + Vite + TypeScript
- Pinia, Vue Router 4
- 네이버 지도 API (Maps JavaScript API v3)
- axios

## 개발 서버 실행

```bash
npm install
npm run dev
```

## 빌드

```bash
npm run build
```

## 환경변수

```
VITE_NAVER_MAP_CLIENT_ID=...
VITE_API_BASE_URL=https://api.hehehe.kr
```
